# Data Structures and Algorithms in C++

Independent C++ solutions using recursion, merge sort, stacks, linked nodes, trees, graph traversal, and priority queues.

Coursework by **Ali Amiri**, Sharif University of Technology. Semester 7 — Data Structures.

## Build and run

Each `hw*/q*/main.cpp` is a separate console program with its own input format.

```bash
g++ -std=c++17 -O2 hw1/q1/main.cpp -o solution
./solution < input.txt
```

The original assignment numbering is retained. Problem statements are excluded, so input formats should be read from the corresponding program. `hw5/q1` combines priority-queue graph processing with bridge traversal. The folder marked as a friend's solution in the source archive is excluded. Compilation alone does not establish judge acceptance.
